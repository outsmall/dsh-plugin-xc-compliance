## Import into your personal plugins

This is the Kimi Work personal-plugin import path. It does not publish the plugin to Kimi's public marketplace.

1. Open the latest Kimi Work desktop app.
2. Open Plugin Builder by entering `/` in a conversation or choose **Plugins → Custom plugin** in Plugin Center.
3. Give Plugin Builder only this Kimi subdirectory: https://github.com/outsmall/dsh-plugin-xc-compliance/tree/main/kimi
4. Ask it to convert the native `kimi.plugin.json` into a personal plugin. Do not import the repository root, which contains other platform packages.
5. Before registering the converted plugin, confirm that its MCP URL is exactly `https://agent.xiaochucompliance.com/agent-tools/mcp/kimi` and that it exposes only `search_legal_sources` and `search_risk_cases`.
6. Open **Plugins → Personal**, install the converted plugin, and check that its MCP connection is available.
7. In a conversation, invoke the plugin with `/` and run a read-only legal-source query and a historical-alert query. Confirm that the tool results appear before relying on the answer.

Kimi Work's official guide documents importing plugin repositories and converting a selected subdirectory into a personal plugin. Official marketplace publication is a separate process.

## What it does

The plugin combines an EU product-compliance reference Skill with two read-only evidence tools. It searches frozen official legal excerpts and historical public safety alerts. It does not perform a live legal check, certify a product, or approve market access.

Example read-only checks:
- Retrieve GPSR Article 16(1) and its official EUR-Lex source.
- Retrieve Safety Gate notification 0988/07 and its official detail link.

If the plugin returns no tool result, say the evidence could not be retrieved and do not imply the query succeeded. Do not connect another platform's MCP endpoint as a substitute.

Send only minimal generic product or hazard terms, or an exact public official URL and locator. Do not send customer files, personal details, credentials, or confidential information.

The Chinese and English answer footer is plain text and contains the website domain, not a clickable link.
